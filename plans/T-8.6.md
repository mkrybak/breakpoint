# T-8.6 — Circuit breaker

## Goal

Add an optional circuit breaker to any sync edge. It watches the failure rate of the calls that actually reach the target. Once that rate stays above a threshold for N consecutive ticks, the breaker **opens**: for the cooldown, calls fail fast at the caller, put no load on the target and schedule no retries. Then it goes **half-open** for one tick and lets 10% of the edge's calls through as a probe. If the probe's failure rate is at or under the threshold the breaker **closes**, otherwise it re-opens and the cooldown restarts. Each transition writes an event-log line. The edge inspector gets a "breaker" checkbox that fills in sensible defaults and exposes three fields (threshold, trip window, cooldown). The frame reports each breaker's phase so the canvas can draw an open breaker. A new golden test shows the T-8.5 retry storm recovering once the breaker is on.

**Accept (verbatim):** An optional per-edge breaker: it opens when the target's error rate passes a threshold for N ticks, fails fast (no load on the target, errors at the caller) while open, then half-opens after a cooldown. Event log lines for open, half-open and closed. Golden test: the T-8.5 retry storm recovers with the breaker on.

**Design calls I made (lead, review):**
- **What trips the breaker is the failure rate of this edge's calls** (drops at the target plus timeouts, A3), not the target node's aggregate drop rate. A real breaker sits in the caller and counts its own call failures, so a slow target that times calls out trips it even with zero drops. For a single-caller target the two rates are the same thing. The comparison is a strict `>` ("passes a threshold"), the same convention the verdict uses. A tick with nothing attempted counts as "not over" and resets the streak.
- **Exact semantics.** At the start of a tick, an open breaker that has completed `cooldownTicks` open ticks turns half-open (and logs it). The phase then gates the tick: closed lets everything through, open lets nothing through, half-open lets `BREAKER_PROBE_FRACTION = 0.1` through. At the end of the tick, using that tick's `failRate`:
  - closed: `streak = failRate > threshold ? streak + 1 : 0`, and it opens when `streak ≥ tripTicks`.
  - open: counts the tick.
  - half-open: `failRate > threshold` re-opens it (the cooldown restarts), otherwise it closes.
  So the probe is exactly one tick of 10% of the edge's calls. The other 90% fail fast in that tick, and the decision is made at the end of the same tick. The probe is a fixed constant, not user-configurable.
- **Fail fast = partition booking.** The gated-off part of the attempted flow, fresh calls and retry carry alike, is booked into `unroutable[source]`, the same path a partitioned (dead) edge uses. It therefore lands in the caller's `dropped` and in the client-path `errorRate` (T-8.2). Rejected calls schedule **no retries**, because retrying against an open breaker costs the target nothing and still fails. The target sees only the admitted flow, and A3's `failRate` is measured only on that flow, so a breaker never counts its own rejections.
- **Latency.** T-8.4's weights are flow-derived, so an open edge (flow 0) adds 0 ms and a half-open one adds 10% of the target's path latency. No change to `meanPathMs`.
- **Scope.** Only sync edges get a breaker (any source, LB included). The engine ignores `breaker` on async edges and the UI hides it there. An LB edge's open breaker rejects its own share; it does not reroute to other backends (outlier ejection isn't modelled).
- **UI: a checkbox with exposed fields.** Ticking "breaker" writes `DEFAULT_BREAKER`, and the three number fields appear pre-filled: open at **50**% errors, for **0.5** s, cooldown **5** s. 50% is the Hystrix/resilience4j default. 0.5 s (5 ticks) is fast enough to catch a storm inside a 10 s spike and slow enough to ignore a one-tick blip. 5 s is the Hystrix sleep window and fits 30 s scenarios. I exposed the fields because the threshold and cooldown are exactly what an interviewer asks about, and the defaults keep the one-click path. The limits are threshold 5–95% (step 5), trip window 0.1–10 s (step 0.1) and cooldown 0.5–60 s (step 0.5). They live in one constant, `BREAKER_LIMITS`, which both the UI and the engine's clamp read.
- **Data is in seconds, the engine works in ticks:** `ticks = max(1, round(sec × 10))`, the same `secToTick` convention as the stress rules.
- **Frame:** `perEdge[id].breaker` is present only on edges with a resolved breaker. It holds the phase **that governed this tick's traffic**, so it always matches the same frame's `rps`. The frame where the breaker trips still reads `closed` but carries the "open" log line. A half-open frame reads `half-open` with probe-sized rps.
- **Action log (grader):** turning the breaker on or off records `config_changed` with the detail "enabled/disabled circuit breaker on A → B". Field edits aren't recorded, to avoid noise from typing.

**Engine rules:** `breaker.ts` is a leaf inside `src/lib/simulation`. It imports only types from `@/lib/core` and takes `ticksPerSec` as an argument, so it adds no import cycle with `engine.ts`.   
   ```ts
   import type { BreakerPhase, DesignEdge, EdgeBreaker } from "@/lib/core";

   export const DEFAULT_BREAKER: EdgeBreaker = { errorThreshold: 0.5, tripAfterSec: 0.5, cooldownSec: 5 };
   /** UI input ranges and the engine's clamp — one source of truth. */
   export const BREAKER_LIMITS = {
     errorThreshold: { min: 0.05, max: 0.95, step: 0.05 },
     tripAfterSec: { min: 0.1, max: 10, step: 0.1 },
     cooldownSec: { min: 0.5, max: 60, step: 0.5 },
   } as const;
   /** Share of the edge's calls a half-open breaker lets through for its one probe tick. */
   export const BREAKER_PROBE_FRACTION = 0.1;

   export interface ResolvedBreaker { threshold: number; tripTicks: number; cooldownTicks: number }
   export interface BreakerState {
     phase: BreakerPhase;
     /** consecutive closed ticks over the threshold */
     streak: number;
     /** open ticks completed since it (re)opened */
     openTicks: number;
   }
   export const CLOSED_BREAKER: BreakerState = { phase: "closed", streak: 0, openTicks: 0 };

   function clampTo(value: number, limit: { min: number; max: number }, fallback: number): number {
     return Number.isFinite(value) ? Math.min(limit.max, Math.max(limit.min, value)) : fallback;
   }

   /** null = no breaker (absent, or an async edge). Junk values clamp / fall back to defaults. */
   export function resolveBreaker(edge: DesignEdge, ticksPerSec: number): ResolvedBreaker | null {
     if (edge.kind !== "sync" || !edge.breaker) return null;
     const b = edge.breaker;
     const L = BREAKER_LIMITS;
     const D = DEFAULT_BREAKER;
     return {
       threshold: clampTo(b.errorThreshold, L.errorThreshold, D.errorThreshold),
       tripTicks: Math.max(1, Math.round(clampTo(b.tripAfterSec, L.tripAfterSec, D.tripAfterSec) * ticksPerSec)),
       cooldownTicks: Math.max(1, Math.round(clampTo(b.cooldownSec, L.cooldownSec, D.cooldownSec) * ticksPerSec)),
     };
   }

   /** Start of tick: maybe half-open, then the fraction of the edge's calls admitted this tick. */
   export function beginBreakerTick(state: BreakerState, cfg: ResolvedBreaker):
     { state: BreakerState; pass: number; halfOpened: boolean } {
     if (state.phase === "open" && state.openTicks >= cfg.cooldownTicks) {
       return { state: { phase: "half-open", streak: 0, openTicks: 0 }, pass: BREAKER_PROBE_FRACTION, halfOpened: true };
     }
     const pass = state.phase === "closed" ? 1 : state.phase === "open" ? 0 : BREAKER_PROBE_FRACTION;
     return { state, pass, halfOpened: false };
   }

   /** End of tick: fold this tick's failure rate (over admitted calls only). */
   export function endBreakerTick(state: BreakerState, cfg: ResolvedBreaker, failRate: number):
     { state: BreakerState; transition?: "open" | "closed" } {
     const over = failRate > cfg.threshold;
     if (state.phase === "open") return { state: { ...state, openTicks: state.openTicks + 1 } };
     if (state.phase === "half-open") {
       return over
         ? { state: { phase: "open", streak: 0, openTicks: 0 }, transition: "open" }
         : { state: CLOSED_BREAKER, transition: "closed" };
     }
     const streak = over ? state.streak + 1 : 0;
     if (streak >= cfg.tripTicks) return { state: { phase: "open", streak: 0, openTicks: 0 }, transition: "open" };
     return { state: { ...state, streak } };
   }

   const breakerMessage: Record<BreakerPhase, (path: string, failPct: number) => string> = {
     open: (path, pct) => `${path} breaker open at ${pct}% errors — failing fast`,
     "half-open": (path) => `${path} breaker half-open — probing`,
     closed: (path) => `${path} breaker closed — traffic restored`,
   };

   /** Log line for a breaker transition; path = "Source → Target" node labels. */
   export function breakerEvent(sourceLabel: string, targetLabel: string, to: BreakerPhase, failRate = 0): string {
     return breakerMessage[to](`${sourceLabel} → ${targetLabel}`, Math.round(failRate * 100));
   }
   ```
