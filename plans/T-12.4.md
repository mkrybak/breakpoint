# T-12.4: Short edges stay readable

## Goal

On short edges the canvas currently hides its own information. In `examples/retry-storm.json`'s seeded layout (nodes at x 0/250/500, `w-44` = 176 px wide) each edge spans only 68 flow-px between handles. The open edge editor (about 210 × 32 px) sits centred on the edge, so it covers both endpoint nodes' labels. The idle chip (`×1 · ⏱200 ↻3 · breaker open` after T-12.3, about 170 px) covers the whole stroke, including T-8.6's rose "breaker open" stroke. This task adds two pure layout rules and wires them into `FlowEdge.tsx`. (1) If the chip text doesn't fit on the stroke with stroke still visible on both sides, it collapses to a small state icon. (2) If the editor's box would overlap either endpoint node, it moves below both nodes. The rules work in flow coordinates, so they don't depend on zoom.

**Accept:** On an edge too short for its label, the open popover sits beside the edge rather than covering the target node's label, and the chip collapses to an icon so the edge stroke (including the rose "breaker open" stroke) stays visible. Screenshots: the seeded `retry-storm.json` layout, with no node dragging.

**Geometry (verified):** React Flow v12 puts `sourceX` at the right handle's outer edge (node.x + 176 + 3) and `targetX` at the left handle's outer edge (node.x − 3). So retry-storm's spans are 250 − 179 − 3 = **68 px** for both edges. The Quick starter (x 0/280/560) spans **98 px**, and `twitter.json` spans 18 px. At 10 px Geist Mono, one character is 6 px wide (0.6 em). The chip has `px-1.5`, so it adds 12 px.

**Calls made in this plan (lead, please review):**
1. **The chip width is estimated from the text, not measured in the DOM.** Width = code points × 6 + 12. The chip collapses when `width + 2 × 10 > span`, i.e. it needs at least 10 px of stroke (or arrowhead) visible on each side. Measuring the DOM would oscillate: the collapsed chip has a different width, so you would have to measure an off-screen copy. The estimate is deterministic and unit-testable. Effects: retry-storm's `×1` chip (24 px) stays full on the Client edge, and `×1 · ⏱200 ↻3` (84 px) collapses. On the starter layout (98 px), anything up to 11 characters stays full (`×1`, `50% · auto`, `×1 · async`), but `×1 · ⏱200 ↻3` collapses.
2. **The collapsed icon keeps hot amplification readable.** The milestone demo needs `↻ 3.6× load` readable on retry-storm's short edge, and T-12.3's accept says "readable without selecting". So the collapsed badge is icon-only, except while amplification is amber: then it shows the Repeat icon plus `3.6×` (46 px wide, leaving 11 px of stroke on each side of a 68 px edge). Priority, highest first: breaker open (rose `ShieldOff`, icon only, so the rose stroke shows), breaker probing (amber `ShieldAlert`), amplification amber (`Repeat` + `N.N×`), anything else (muted `Ellipsis`). The full chip text stays in an `sr-only` span. There is no hover tooltip: the chip layer is `pointer-events: none` (as today) so clicks still fall through to the edge path and select it. All settings remain visible in the Edge inspector.
3. **"Beside the edge" means below both endpoint nodes.** The popover box is estimated at 210 × 32 for call edges and 250 × 32 for split edges (measured from `screenshots/T-8.5/01-edge-panel.png`: 181 × 28 screen px at zoom 0.88). It's centred on the label point. If that box overlaps either endpoint node's rect (from `useInternalNode`), the popover moves to centre x = `labelX` and top = the lowest endpoint bottom + 8 px. It always goes below, never above, so the position is predictable. On typical layouts (gap under about 220 px) the editor now always sits below the nodes. On long edges it stays on the edge as before.
4. **Known limit:** below a 40 px span (e.g. `twitter.json`'s 18 px), even the 20 px icon covers most of the stroke. We accept that. Nodes nearly touching is an edge case, and today's chip covers that stroke completely.

### 1. New `app/src/components/canvas/edges/edge-layout.ts`

Complete file:

```ts
import type { ChipSegment, ChipTone } from "./edge-chip";

/** A point or box in React Flow's flow coordinates (zoom-independent). */
export interface FlowPoint { x: number; y: number }
export interface FlowRect { x: number; y: number; width: number; height: number }

/** 10px Geist Mono advance (0.6em) and the chip's px-1.5 padding. */
export const CHIP_CHAR_PX = 6;
export const CHIP_PAD_PX = 12;
/** Stroke (or arrowhead) that must stay visible on each side of the chip. */
export const MIN_VISIBLE_STROKE_PX = 10;
/** Estimated open edge editor (T-8.3 popover) box, flow px. */
export const POPOVER_SIZE = {
  call: { width: 210, height: 32 },
  split: { width: 250, height: 32 },
} as const;
/** Gap between the displaced popover and the nodes above it. */
export const POPOVER_GAP_PX = 8;

/** Straight-line length between the edge's handle points. */
export function edgeSpan(source: FlowPoint, target: FlowPoint): number {
  return Math.hypot(target.x - source.x, target.y - source.y);
}

/** Estimated rendered width of the chip for this text. */
export function chipWidth(text: string): number {
  return [...text].length * CHIP_CHAR_PX + CHIP_PAD_PX;
}

/** True when the full chip fits with ≥ MIN_VISIBLE_STROKE_PX of stroke on both sides. */
export function chipFits(text: string, span: number): boolean {
  return chipWidth(text) + 2 * MIN_VISIBLE_STROKE_PX <= span;
}

/** Strict overlap: touching edges don't count. */
export function rectsOverlap(a: FlowRect, b: FlowRect): boolean {
  return (
    a.x < b.x + b.width &&
    b.x < a.x + a.width &&
    a.y < b.y + b.height &&
    b.y < a.y + a.height
  );
}

/**
 * Centre point for the open edge editor. On the label point unless that box
 * overlaps an endpoint node; then centred under the lowest endpoint's bottom.
 */
export function placePopover(
  label: FlowPoint,
  size: { width: number; height: number },
  endpoints: FlowRect[],
): { center: FlowPoint; displaced: boolean } {
  const box: FlowRect = {
    x: label.x - size.width / 2,
    y: label.y - size.height / 2,
    width: size.width,
    height: size.height,
  };
  if (!endpoints.some((r) => rectsOverlap(box, r))) {
    return { center: label, displaced: false };
  }
  const bottom = Math.max(...endpoints.map((r) => r.y + r.height));
  return {
    center: { x: label.x, y: bottom + POPOVER_GAP_PX + size.height / 2 },
    displaced: true,
  };
}

export type CollapsedIcon = "shield-off" | "shield-alert" | "repeat" | "ellipsis";

export interface CollapsedChip {
  icon: CollapsedIcon;
  tone: ChipTone;
  /** "" except the amplification value, e.g. "3.6×". */
  text: string;
}

/** The icon a too-long chip collapses to: its most urgent segment wins. */
export function collapsedChip(
  segments: ChipSegment[],
  amplification: number | null,
): CollapsedChip {
  const breaker = segments.find((s) => s.key === "breaker");
  if (breaker?.tone === "rose") return { icon: "shield-off", tone: "rose", text: "" };
  if (breaker?.tone === "amber") return { icon: "shield-alert", tone: "amber", text: "" };
  const amp = segments.find((s) => s.key === "amplification");
  if (amp?.tone === "amber" && amplification !== null) {
    return {
      icon: "repeat",
      tone: "amber",
      text: `${(Math.round(amplification * 10) / 10).toFixed(1)}×`,
    };
  }
  return { icon: "ellipsis", tone: "muted", text: "" };
}
```

function nodeRect(node: InternalNode | undefined): FlowRect | null {
  const width = node?.measured.width;
  const height = node?.measured.height;
  if (!node || !width || !height) return null;
  const { x, y } = node.internals.positionAbsolute;
  return { x, y, width, height };
