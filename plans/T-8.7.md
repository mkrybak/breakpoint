# T-8.7: More honest tail latency

## Goal

Replace the fixed `p95 = 1.6 × mean` with an estimate that has a real tail. Every node already uses M/M/1 for its mean time-in-system, and in M/M/1 that time is exponential (σ = mean). So each node now reports a **variance** along with its mean, and the engine folds both moments along the sync path the same way it folds the mean today: sequential calls add, and LB splits form a mixture. Then p95 = mean + 2σ at the entry. The estimate is cheap (two numbers per node in the existing reverse-topo pass), deterministic, and explainable in one sentence. A single exponential hop gets mean + 2·mean = 3.0 × mean, which matches ln 20 ≈ 2.996 to within 0.2%. A long chain of idle hops gets a relatively thinner tail. One hot node dominates the tail. A cache whose misses are slow widens it. A one-sentence native tooltip on the HUD's p95 card explains this, in both the Quick and Practice HUDs.

**Accept (verbatim):** Replace the fixed `p95 = 1.6 × mean` (`engine.ts:287`). Note that M/M/1 time-in-system is exponential, so p95 ≈ ln(20) × mean ≈ 3.0 × mean, meaning the current factor *understates* the tail. The plan picks and documents an approximation (per-node percentile composition, or a utilization-dependent factor) and explains it in the UI tooltip. **Why this approximation (record it in Decisions).**
- A utilization-dependent factor (`k(util) × mean`) can't say which node's util to use, and it misses mixtures. A cache at 80% hits with slow misses really does have a p95 near the miss latency.
- Summing per-node p95s overstates the tail of a sum. Averaging per-node p95s for mixtures understates it.
- Moments compose exactly for sums (means add, variances add if the hops are independent) and for mixtures (`Σw(v+m²) − (Σwm)²`). Mean + 2σ then reproduces the exponential's p95 for one hop, comes within about 2% of Erlang-n's p95, and gets the cache case right. Prototype check: a mixture of 80% at 1 ms and 20% at 50 ms gives 50.0 ms, and the true value is 50.
- The explicit backlog wait (`queueWaitMs`, the visible queue drained at capacity) is treated as a fixed shift with zero variance. Only the M/M/1 part is random.

**Fractional call weights.** A call edge with weight `w` (callsPerRequest × the fraction of the source's traffic that reaches it, for example a cache's miss share) is modeled as N calls, where N is `floor(w)` or `ceil(w)` and its mean is `w`. That is the lowest-variance integer count, with `Var(N) = f(1−f)` and `f = w − floor(w)`. The contribution is then mean `w·m` and variance `w·v + f(1−f)·m²`. With `w ≤ 1` this reduces to the Bernoulli/mixture formula, so a cache miss edge and an LB branch agree.

     ```ts
     /**
      * Mean and variance of client-visible latency (tick-loop step 4), folded
      * in reverse topo order over clientPathTerms. Node n contributes its own
      * latencyMs / latencyVarMs2. Calls add (sequential, independent hops:
      * variances add; a fractional weight w is ⌊w⌋ or ⌈w⌉ calls, adding
      * f(1−f)·m² spread, f = w − ⌊w⌋). An LB split is a mixture: variance +=
      * Σw(v+m²) − (Σw·m)². The mean fold is T-8.4's, term for term in the same
      * order. Zero moments without an entry.
      */
     export function pathMoments(
       graph: DesignGraph,
       prop: PropagationResult,
       outputs: ReadonlyMap<string, NodeModelOutput>,
     ): PathMoments {
       const terms = clientPathTerms(graph, prop, outputs);
       const kindById = new Map(graph.nodes.map((n) => [n.id, n.kind]));
       const moments = new Map<string, PathMoments>();
       for (let i = prop.order.length - 1; i >= 0; i--) {
         const id = prop.order[i];
         const out = outputs.get(id);
         if (!out) continue;
         const split = isSplitSource(kindById.get(id));
         let meanMs = out.latencyMs;
         let varianceMs2 = out.latencyVarMs2;
         let mixMean = 0; // split only: Σ w·m
         let mixSecond = 0; // split only: Σ w·(v + m²)
         for (const { target, weight: w } of terms.get(id) ?? []) {
           const t = moments.get(target) ?? { meanMs: 0, varianceMs2: 0 };
           meanMs += w * t.meanMs;
           if (split) {
             mixMean += w * t.meanMs;
             mixSecond += w * (t.varianceMs2 + t.meanMs * t.meanMs);
           } else {
             const f = w - Math.floor(w);
             varianceMs2 += w * t.varianceMs2 + f * (1 - f) * t.meanMs * t.meanMs;
           }
         }
         if (split) varianceMs2 += Math.max(0, mixSecond - mixMean * mixMean); // float guard
         moments.set(id, { meanMs, varianceMs2 });
       }
       return moments.get(graph.entryNodeId) ?? { meanMs: 0, varianceMs2: 0 };
     }

     /** p95 ≈ mean + 2σ. */
     export function p95FromMoments({ meanMs, varianceMs2 }: PathMoments): number {
       return meanMs + P95_SIGMAS * Math.sqrt(varianceMs2);
     }
     ```
