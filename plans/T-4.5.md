# T-4.5 — Review screen for the grader

## Goal

The app gains a **grader review screen** at `/review/[runId]`: a three-pane read-only view of a
completed mock interview. The left pane is the **action timeline** — every recorded `ActionEvent`,
grouped by interview phase in order; clicking an event restores the design graph as it was at that
moment onto the center canvas. The center pane is a **read-only design canvas** with the sim-replay
scrubber (reused from the design screen) synced to it — scrub the run and the canvas nodes light up
tick-by-tick. The right pane shows the candidate's **phase notes** (read-only, per phase) and the
grader **scorecard** (the existing T-4.4 component, which loads/saves to localStorage). A header
button **exports the whole review as a markdown report** (scores, anchors, feedback, notes, verdict,
timeline).

`runId === designId`: the review reads the same in-session stores the interview wrote
(`design-store`, `sim-store`, `scorecard-store`). This is M4's "review right after your mock" flow —
sim frames and per-action graph snapshots live in memory only, exactly like the design screen's
replay already does. M5's `RunBundle` file import will later repopulate these same stores so the
review works across a reload; until then a hard reload of `/review/[id]` degrades gracefully (final
graph + persisted notes/scorecard, no replay, no per-action snapshots).

Acceptance criteria (verbatim from `tasks/M4-interview-flow.md`):

> **Accept:** Three-pane review: (1) action timeline — chronological, grouped by phase, clicking an
> event restores the graph snapshot at that moment; (2) sim replay scrubber synced to the canvas; (3)
> scorecard. Read-only design view; phase notes visible per phase; export report as markdown.

### Interpretation (decided here — do not deviate)

- **`runId === designId`; the review reads in-session stores.** The grader navigates from the design
  screen (a "Open review screen →" link, added below) to `/review/<same id>`. `design-store` still
  holds the final graph, `actionLog`, `phaseNotes`; `sim-store` still holds the run's `frames` /
  `result` / `runGraph` / `runScenario`; `scorecard-store` loads the scorecard from localStorage by
  id. Nothing new is persisted by this task. This mirrors the existing fact that **sim frames are
  already memory-only** — `Verdict` and `ReplayScrubber` render nothing when `sim-store` is idle, so
  a cold reload simply shows no replay. (2026-07-12 architecture decision: the durable review path is
  M5's exported `RunBundle` file; the review route "loads imported run file" is M5's wiring.)
- **"Restore the graph snapshot at that moment" = per-action in-memory snapshots.** `ActionEvent`
  (frozen in `core`, T-4.3) carries only `{t, phase, kind, detail}` — no graph — and its `detail`
  strings ("added Redis") cannot be losslessly replayed into intermediate graphs. Rather than change
  the frozen schema or the persisted `DesignRecord`, `design-store` gains an **in-memory**
  `actionSnapshots: DesignGraph[]`, one entry per recorded action, captured in `recordAction`. Because
  the store never mutates a graph in place (every edit produces a fresh immutable graph object), a
  snapshot is just a **reference** to the graph object as of that action — zero-copy, negligible
  memory, structurally shared. `actionSnapshots[i]` aligns to `actionLog[i]`. It is reset (to `[]`)
  on `attachDesign`/`importRecord` (which also reset `actionLog`), so the invariant
  `actionSnapshots.length === actionLog.length` holds in-session; on a cold reload it is empty and the
  timeline falls back to the final graph. **Not persisted, not in `DesignRecord`, not in `core`.**
- **The center canvas has two mutually-exclusive views.** Default ("final") view shows the run graph
  (`sim-store.runGraph`, or the current design graph if no run happened) with the reused
  `ReplayScrubber` + `Verdict` overlays driving the live sim overlay. Clicking a timeline event
  switches to "snapshot" view: the canvas shows `actionSnapshots[i]` and the replay overlays are
  hidden; a small banner ("Design as of mm:ss") with a "Back to final design" button returns to the
  default view. The sim overlay on `ComponentNode` still reads `sim-store` in snapshot view — an
  accepted cosmetic MVP simplification (snapshot view is about **structure**, and it is not driven by
  the scrubber).
- **The review canvas is its own read-only component**, not the editable `DesignCanvas` (which is
  bound to `design-store` and would record/autosave if we swapped its graph). It reuses `toFlow`,
  `ComponentNode`, `FlowEdge`, and keeps a local `measured` map — React Flow 12 hides nodes until the
  dimensions it reports are echoed back (02-data-model, T-1.2 fix), so even a read-only canvas must
  handle `onNodesChange` for dimension changes.
- **Markdown export is a pure builder + a DOM download helper**, mirroring `exportDesignFile`. The
  pure `buildReviewReport(...)` lives in `src/persistence/report.ts` (shell) and is unit-tested;
  `exportReportFile(...)` (Blob download) is not tested, same as `exportDesignFile`.
- **The timeline grouping is pure** (`groupActionsByPhase`) and unit-tested, independent of any store
  or the DOM.
- **Scorecard is reused verbatim** — `src/components/review/Scorecard.tsx` already exists (T-4.4) and
  takes `{ id }`. Do not re-implement it.

### 2. `src/components/review/timeline.ts` — pure timeline grouping (new file, shell)

```ts
import type { ActionEvent, ActionKind, Phase } from "@/lib/core";

/** One timeline row: the event plus its index into the full `actionLog`. */
export interface TimelineEntry {
  event: ActionEvent;
  index: number;
}

/** Events for one interview phase, in chronological (log) order. */
export interface PhaseGroup {
  phase: Phase;
  events: TimelineEntry[];
}

/** Canonical phase order (mirrors PHASES in phase-store / PHASES in persistence). */
const PHASE_ORDER: Phase[] = [
  "requirements",
  "entities",
  "api",
  "hld",
  "deepdive",
];

/**
 * Group the action log into per-phase sections in interview order, preserving each
 * event's global index into `actionLog`. Only phases that have events appear.
 * Within a group, events keep their chronological order.
 */
export function groupActionsByPhase(actionLog: ActionEvent[]): PhaseGroup[] {
  const byPhase = new Map<Phase, TimelineEntry[]>();
  actionLog.forEach((event, index) => {
    const list = byPhase.get(event.phase);
    if (list) list.push({ event, index });
    else byPhase.set(event.phase, [{ event, index }]);
  });
  return PHASE_ORDER.filter((phase) => byPhase.has(phase)).map((phase) => ({
    phase,
    events: byPhase.get(phase) ?? [],
  }));
}

/** Compact badge label per action kind, for the timeline. */
export const ACTION_KIND_LABEL: Record<ActionKind, string> = {
  node_added: "add",
  node_removed: "remove",
  node_renamed: "rename",
  config_changed: "config",
  edge_added: "connect",
  edge_removed: "disconnect",
  note_edited: "note",
  phase_started: "phase",
  sim_run: "run",
  chaos_injected: "chaos",
};
```

### 3. `src/components/review/ActionTimeline.tsx` — the timeline pane (new file, shell)

```tsx
"use client";

import type { ActionEvent } from "@/lib/core";
import { formatClock, phaseConfig } from "@/stores/phase-store";
import {
  ACTION_KIND_LABEL,
  groupActionsByPhase,
} from "@/components/review/timeline";

const HEADING =
  "text-xs font-semibold tracking-wide text-neutral-400 uppercase";

export function ActionTimeline({
  actionLog,
  selectedIndex,
  onSelect,
}: {
  actionLog: ActionEvent[];
  selectedIndex: number | null;
  onSelect: (index: number) => void;
}) {
  const groups = groupActionsByPhase(actionLog);

  return (
    <section className="flex flex-col gap-5">
      <h2 className={HEADING}>Action timeline</h2>
      {actionLog.length === 0 && (
        <p className="text-xs text-neutral-600">No actions recorded.</p>
      )}
      {groups.map((group) => (
        <div key={group.phase}>
          <h3 className={HEADING}>{phaseConfig(group.phase).label}</h3>
          <ol className="mt-1.5 flex flex-col gap-0.5">
            {group.events.map(({ event, index }) => {
              const active = index === selectedIndex;
              return (
                <li key={index}>
                  <button
                    type="button"
                    onClick={() => onSelect(index)}
                    aria-pressed={active}
                    className={[
                      "flex w-full items-center gap-2 rounded px-2 py-1 text-left text-xs",
                      active
                        ? "border border-sky-500/60 bg-sky-500/15 text-sky-200"
                        : "border border-transparent text-neutral-300 hover:bg-neutral-800/60",
                    ].join(" ")}
                  >
                    <span className="shrink-0 font-mono text-[10px] text-neutral-500">
                      {formatClock(event.t)}
                    </span>
                    <span className="shrink-0 rounded bg-neutral-800 px-1.5 py-0.5 font-mono text-[9px] tracking-wide text-neutral-400 uppercase">
                      {ACTION_KIND_LABEL[event.kind]}
                    </span>
                    <span className="truncate">{event.detail}</span>
                  </button>
                </li>
              );
            })}
          </ol>
        </div>
      ))}
    </section>
  );
}
```

### 4. `src/components/review/ReviewCanvas.tsx` — read-only replay canvas (new file, shell)

Mirrors `DesignCanvas` but strips all editing. Keeps a local `measured` map so React Flow reveals
the nodes (the visibility gotcha). Reuses `ComponentNode` (so the sim overlay works during replay)
and `FlowEdge`.

```tsx
"use client";

import {
  Background,
  Controls,
  ReactFlow,
  ReactFlowProvider,
  type NodeChange,
} from "@xyflow/react";
import "@xyflow/react/dist/style.css";
import { useCallback, useMemo, useState } from "react";
import type { DesignGraph } from "@/lib/core";
import { FlowEdge } from "@/components/canvas/edges/FlowEdge";
import { ComponentNode } from "@/components/canvas/nodes/ComponentNode";
import {
  toFlow,
  type ComponentFlowEdge,
  type ComponentFlowNode,
  type NodeMeasurements,
} from "@/stores/flow-adapter";

const nodeTypes = { component: ComponentNode };
const edgeTypes = { flow: FlowEdge };

function ReviewCanvasInner({ graph }: { graph: DesignGraph }) {
  const [measured, setMeasured] = useState<NodeMeasurements>({});

  const { nodes, edges } = useMemo(
    () => toFlow(graph, [], measured, []),
    [graph, measured],
  );

  // Read-only: the only change we act on is React Flow reporting node dimensions —
  // echo them back or the nodes stay visibility:hidden (02-data-model, T-1.2 fix).
  // Position / selection / removal changes are ignored.
  const onNodesChange = useCallback(
    (changes: NodeChange<ComponentFlowNode>[]) => {
      setMeasured((prev) => {
        let next = prev;
        for (const change of changes) {
          if (change.type === "dimensions" && change.dimensions) {
            if (next === prev) next = { ...prev };
            next[change.id] = {
              width: change.dimensions.width,
              height: change.dimensions.height,
            };
          }
        }
        return next;
      });
    },
    [],
  );

  return (
    <ReactFlow<ComponentFlowNode, ComponentFlowEdge>
      nodes={nodes}
      edges={edges}
      onNodesChange={onNodesChange}
      nodeTypes={nodeTypes}
      edgeTypes={edgeTypes}
      nodesDraggable={false}
      nodesConnectable={false}
      elementsSelectable={false}
      deleteKeyCode={null}
      fitView
      colorMode="dark"
    >
      <Background />
      <Controls showInteractive={false} />
    </ReactFlow>
  );
}

export function ReviewCanvas({ graph }: { graph: DesignGraph }) {
  return (
    <ReactFlowProvider>
      <ReviewCanvasInner graph={graph} />
    </ReactFlowProvider>
  );
}
```

### 5. `src/persistence/report.ts` — markdown report builder + download (new file, shell)

```ts
import type { ActionEvent, Phase, Scenario, Verdict } from "@/lib/core";
import {
  RECOMMENDATION_OPTIONS,
  RUBRIC,
  type Recommendation,
  type Scorecard,
} from "@/lib/grading";

export interface ReviewReportInput {
  designName: string;
  scenario: Scenario | null;
  verdict: Verdict | null;
  phaseNotes: Record<Phase, string>;
  actionLog: ActionEvent[];
  scorecard: Scorecard;
}

/** Whole seconds → "mm:ss" (self-contained; keeps persistence free of store imports). */
function mmss(sec: number): string {
  const c = Math.max(0, Math.floor(sec));
  return `${String(Math.floor(c / 60)).padStart(2, "0")}:${String(c % 60).padStart(2, "0")}`;
}

function recommendationLabel(value: Recommendation): string {
  return RECOMMENDATION_OPTIONS.find((o) => o.value === value)?.label ?? value;
}

/** Render a full grader report as markdown (scores, anchors, notes, verdict, timeline). */
export function buildReviewReport(input: ReviewReportInput): string {
  const { designName, scenario, verdict, phaseNotes, actionLog, scorecard } =
    input;
  const lines: string[] = [];

  lines.push(`# Review — ${designName}`, "");
  lines.push(
    `**Overall recommendation:** ${recommendationLabel(scorecard.overall)}`,
    "",
  );
  if (scenario) {
    const outcome = verdict ? (verdict.passed ? "passed" : "failed") : "not run";
    lines.push(`**Scenario:** ${scenario.name} — ${outcome}`, "");
  }

  lines.push("## Scores", "");
  for (const rubric of RUBRIC) {
    const phaseScore = scorecard.rubricScores[rubric.phase];
    const anchor =
      rubric.levels.find((l) => l.score === phaseScore.score)?.anchor ?? "";
    lines.push(`### ${rubric.title} — ${phaseScore.score}/5`, "", anchor, "");
    const note = phaseNotes[rubric.phase]?.trim();
    if (note) lines.push("**Candidate notes:**", "", note, "");
    const feedback = phaseScore.feedbackMd.trim();
    if (feedback) lines.push("**Feedback:**", "", feedback, "");
  }

  if (verdict) {
    lines.push("## Simulation verdict", "", verdict.passed ? "Passed." : "Failed.", "");
    for (const failure of verdict.failures) {
      lines.push(`- ${failure.criterion} @ ${failure.atSec}s — ${failure.detail}`);
    }
    for (const advisory of verdict.advisories) {
      lines.push(`- advisory: ${advisory}`);
    }
    if (verdict.failures.length > 0 || verdict.advisories.length > 0) {
      lines.push("");
    }
  }

  lines.push("## Action timeline", "");
  if (actionLog.length === 0) {
    lines.push("_No actions recorded._", "");
  } else {
    for (const event of actionLog) {
      lines.push(`- \`${mmss(event.t)}\` (${event.phase}) ${event.detail}`);
    }
    lines.push("");
  }

  return lines.join("\n");
}

/** Triggers a browser download of the report as <slug>.review.md (mirrors exportDesignFile). */
export function exportReportFile(designName: string, markdown: string): void {
  const slug =
    designName
      .toLowerCase()
      .replace(/[^a-z0-9]+/g, "-")
      .replace(/^-+|-+$/g, "") || "review";
  const blob = new Blob([markdown], { type: "text/markdown" });
  const url = URL.createObjectURL(blob);
  const anchor = document.createElement("a");
  anchor.href = url;
  anchor.download = `${slug}.review.md`;
  anchor.click();
  URL.revokeObjectURL(url);
}
```

```tsx
import type { Phase } from "@/lib/core";
import { ReplayScrubber } from "@/components/hud/ReplayScrubber";

import { Scorecard } from "@/components/review/Scorecard";

import { useDesignStore } from "@/stores/design-store";

  "text-xs font-semibold tracking-wide text-neutral-400 uppercase";

  const graph = useDesignStore((s) => s.graph);
  const actionLog = useDesignStore((s) => s.actionLog);

          type="button"
          onClick={onExport}
          className="ml-auto flex items-center gap-1 rounded-lg border border-neutral-700 bg-neutral-900 px-2.5 py-1 text-xs font-medium text-neutral-200 hover:border-neutral-500"
        >
          <Download className="h-3.5 w-3.5" /> Export report
        </button>
      </header>

      <div className="flex min-h-0 flex-1">
        <aside className="w-80 shrink-0 overflow-y-auto border-r border-neutral-800 p-3">
          <ActionTimeline
            actionLog={actionLog}
            selectedIndex={selected}
            onSelect={setSelected}
          />
        </aside>

          <Scorecard id={runId} />
```
