# T-7.3 — Starter design + starter scenario

## Goal

Ship the data behind Quick mode's first impression: a wired, configured Client → App server → SQL database design, plus a gentle 30 s steady-load scenario that the design passes with plenty of headroom. The scenario goes into a new **Quick-only scenario list** that is kept apart from the shared presets (Practice's picker and the landing page's "Built-in stress tests" keep showing exactly the three M3 presets). The list holds only the starter for now. T-7.6 appends the four challenge scenarios to it, and adding one means adding a JSON file plus one array entry. T-7.4 (landing Quick card), T-7.5 ("More scenarios") and T-7.6 (challenges) import what this task exports. No UI changes in this task.

**Accept (verbatim):** Client → App server → SQL database, wired and configured. A gentle steady-load starter scenario (~30s). A test asserts `runSimulation(starter, starterScenario)` **passes**, so the first impression is green.

   ```json

     "durationSec": 30,
     "baseRps": 1500,
     "readRatio": 0.8,
     "timeline": [],
     "pass": { "p95Ms": 200, "maxErrorRate": 0.01 },
   ```

2. **Edit `app/src/lib/scenarios/index.ts`.**
   - Add the import next to the other preset imports: `import starter from "./presets/starter.json";`
   - Directly after `getScenarioPreset`, add:
     ```ts
     /** Quick mode's first scenario: steady load the starter design passes. */
     export const STARTER_SCENARIO: Scenario = requirePreset(starter);

     /**
      * Scenarios offered only in Quick mode, kept apart from SCENARIO_PRESETS
      * (Practice's picker and the landing page never list these). Order is
      * the display order; the starter stays first. To add one: drop a JSON
      * file in presets/ and append one requirePreset(...) entry here.
      */
     export const QUICK_SCENARIOS: readonly Scenario[] = [STARTER_SCENARIO];

     export function listQuickScenarios(): readonly Scenario[] {
       return QUICK_SCENARIOS;
     }

     export function getQuickScenario(id: string): Scenario | undefined {
       return QUICK_SCENARIOS.find((scenario) => scenario.id === id);
     }
     ```
   - Leave `SCENARIO_PRESETS`, `listScenarioPresets` and `getScenarioPreset` as they are.

3. **Create `app/src/components/quick/starter.ts`:**
   ```ts
   import type { DesignGraph } from "@/lib/core";

   /** Default name for a design created from the Quick card (no naming step). */
   export const QUICK_DESIGN_NAME = "Quick simulation";

   /**
    * Quick mode's starter: Client → App server → SQL database, configured with
    * the registry defaults a palette drop would give. Sized so it passes
    * STARTER_SCENARIO comfortably (app server at ~37% util).
    */
   const STARTER_GRAPH: DesignGraph = {
     entryNodeId: "client",
     nodes: [
       { id: "client", kind: "client", label: "Client", position: { x: 0, y: 0 }, config: {} },
       { id: "app", kind: "app_server", label: "App server", position: { x: 280, y: 0 }, config: { replicas: 1 } },
       {
         id: "db",
         kind: "db_sql",
         label: "SQL database",
         position: { x: 560, y: 0 },
         config: { replicas: 0, sharded: false, readYourWrites: false },
       },
     ],
     edges: [
       { id: "e-client-app", source: "client", target: "app", trafficShare: 1, kind: "sync" },
       { id: "e-app-db", source: "app", target: "db", trafficShare: 1, kind: "sync" },
     ],
   };

   /** A fresh deep copy each call, so a new design never shares objects with the constant. */
   export function starterGraph(): DesignGraph {
     return structuredClone(STARTER_GRAPH);
   }
   ```
   Format multi-line where Prettier wants it. The values above are binding. Fixed node ids are fine: each design is its own record, and nodes added later get UUIDs.

4. **Extend `app/tests/scenarios.test.ts`.**
   - Extend the scenarios import with `getQuickScenario`, `listQuickScenarios`, `QUICK_SCENARIOS`, `STARTER_SCENARIO`. Add `import { getComponentDef } from "../src/lib/registry";`, `import { validateGraph } from "../src/lib/validation";` and `import { starterGraph } from "../src/components/quick/starter";`. (`getComponentDef` is already exported from `src/lib/registry/index.ts`.)
   - Add a new block:
     ```ts
     describe("quick scenarios + starter design", () => {
       it("the Quick list starts with the starter and is separate from the shared presets", () => {
         expect(QUICK_SCENARIOS[0]).toBe(STARTER_SCENARIO);
         expect(listQuickScenarios()).toBe(QUICK_SCENARIOS);
         expect(getQuickScenario("starter")).toBe(STARTER_SCENARIO);
         expect(getQuickScenario("black-friday")).toBeUndefined();
         expect(getScenarioPreset("starter")).toBeUndefined();
         const presetIds = new Set(SCENARIO_PRESETS.map((s) => s.id));
         const quickIds = QUICK_SCENARIOS.map((s) => s.id);
         expect(new Set(quickIds).size).toBe(quickIds.length);
         expect(quickIds.filter((id) => presetIds.has(id))).toEqual([]);
       });

       it("the starter scenario is gentle steady load, ~30s", () => {
         expect(STARTER_SCENARIO.durationSec).toBe(30);
         expect(STARTER_SCENARIO.timeline).toEqual([]);
       });

       it("the starter design is Client → App server → SQL database, wired, with no warnings", () => {
         const graph = starterGraph();
         expect(graph.nodes.map((n) => n.kind)).toEqual(["client", "app_server", "db_sql"]);
         expect(graph.entryNodeId).toBe("client");
         expect(graph.edges.map((e) => [e.source, e.target])).toEqual([
           ["client", "app"],
           ["app", "db"],
         ]);
         expect(validateGraph(graph)).toEqual([]);
         for (const node of graph.nodes) {
           expect(Object.keys(node.config).sort()).toEqual(
             getComponentDef(node.kind).configFields.map((f) => f.key).sort(),
           );
         }
       });

       it("starterGraph returns a fresh copy each call", () => {
         const a = starterGraph();
         a.nodes[1].config.replicas = 9;
         expect(starterGraph().nodes[1].config.replicas).toBe(1);
       });

       it("runSimulation(starter, starterScenario) passes with headroom, deterministically", () => {
         const result = runSimulation(starterGraph(), STARTER_SCENARIO);
         expect(result.verdict.passed).toBe(true);
         expect(result.frames.length).toBe(STARTER_SCENARIO.durationSec * 10);
         const worstP95 = Math.max(...result.frames.map((f) => f.p95Ms));
         expect(worstP95).toBeLessThan(STARTER_SCENARIO.pass.p95Ms / 2);
         expect(result.frames.every((f) => f.errorRate === 0)).toBe(true);
         expect(runSimulation(starterGraph(), STARTER_SCENARIO)).toEqual(result);
       });
     });
     ```
   - Don't touch the existing tests.
