# T-5.2 — Run bundle export/import

## Goal

**Accept (verbatim):** Export `<name>.breakpoint.json` (`RunBundle`: design + frozen scenario + result + optional scorecard); review screen imports via file picker/drag-drop; hand-rolled schema guard rejects malformed bundles with a readable error; grader re-exports with scorecard filled; round-trip test: export → import → identical replay.

When done: the review screen has an **Export bundle** button (visible once a run exists) that downloads `<slug>.breakpoint.json` — a `RunBundle` of the design, the frozen run scenario, the `RunResult`, and the current scorecard. Opening `/review/<anything>` in a fresh browser profile (nothing in localStorage) shows an **ImportDropzone** (click-to-pick or drag-drop). Dropping a valid bundle persists its design + scorecard, rehydrates the sim store so the replay/verdict render, and navigates to `/review/<bundle-design-id>` where the grader can score and re-export. A malformed file shows a readable red error and changes nothing. A persistence round-trip test proves `export → parse → identical frames`.

## Reality vs. spec (read this first)

- **`RunBundle` does not exist yet.** It is defined for the first time here, in `persistence/local.ts` (a persistence concern — see the 2026-07-15 (T-5.2 planning) entry just added to `02-data-model.md#Decisions`).
- **All three guards it needs already exist and are reused, not rewritten:** `parseDesignRecord` (`local.ts`), `parseScenario` (`@/lib/scenarios`, takes a *value* not text), `parseScorecard` (`@/persistence/scorecard`, takes text). The only new guard is `parseRunResult` for the `RunResult` shape.
- **Bundles are files, never localStorage.** Only `DesignRecord` (`bp:design:<id>`) and `Scorecard` (`bp:scorecard:<id>`) persist. `RunResult.frames` is large and transient — it lives in the sim store during a session. So an imported run must repopulate the sim store; a cold page reload of `/review/<id>` legitimately has no frames (documented T-4.5 behavior — replay hidden, timeline falls back to the final graph).
- **The review screen keys everything on the URL's `runId`** (`attachDesign(runId)`, `<Scorecard id={runId} />`, "Back to design" → `/design/{runId}`). So import must **navigate** to `/review/<bundle.design.id>` — hydrating in place would leave those pointed at the wrong id. Zustand stores are module singletons that survive Next client navigation, so `sim-store.loadResult(...)` called before `router.push` stays populated after the push.
- **The Verdict and ReplayScrubber render purely off sim-store `status === "done"` + `frames` + `result`** (confirmed in `Verdict.tsx` / `ReplayScrubber.tsx`). So `loadResult` setting those three is enough to make an imported run look exactly like a just-finished live run.

This is a shell/persistence task: everything touched is under `src/persistence`, `src/components`, `src/stores` — no engine boundary is crossed.

### 2. `src/persistence/local.ts` — RunBundle types, builder, guard, export

Append this block at the **end of the file** (after `isValidActionEvent`; the guards it calls are hoisted `function` declarations, so ordering is fine):

```ts
/** The export file the grader imports: <name>.breakpoint.json (02-data-model). */
export interface RunBundle {
  version: 1;
  design: DesignRecord;
  /** Frozen copy — replay survives preset changes. */
  scenario: Scenario;
  result: RunResult;
  scorecard?: Scorecard;
}

/** Parsing an untrusted bundle file: the value, or a human-readable reason. */
export type RunBundleParseResult =
  | { ok: true; bundle: RunBundle }
  | { ok: false; error: string };

/** Assembles a RunBundle; scorecard is included only when provided. */
export function buildRunBundle(
  design: DesignRecord,
  scenario: Scenario,
  result: RunResult,
  scorecard?: Scorecard,
): RunBundle {
  const bundle: RunBundle = { version: 1, design, scenario, result };
  if (scorecard) bundle.scorecard = scorecard;
  return bundle;
}

/**
 * Hand-rolled schema guard (02-data-model). Reuses parseDesignRecord /
 * parseScenario / parseScorecard and validates the RunResult shape via
 * parseRunResult. Returns a readable error string for the review screen on any
 * malformed section — never throws.
 */
export function parseRunBundle(text: string): RunBundleParseResult {
  let value: unknown;
  try {
    value = JSON.parse(text);
  } catch {
    return { ok: false, error: "This file isn’t valid JSON." };
  }
  if (!isRecord(value)) {
    return { ok: false, error: "This file isn’t a run bundle." };
  }
  if (value.version !== 1) {
    return {
      ok: false,
      error: `Unsupported bundle version ${String(value.version)} (expected 1).`,
    };
  }
  const design = parseDesignRecord(JSON.stringify(value.design));
  if (!design) {
    return { ok: false, error: "The bundle’s design is missing or invalid." };
  }
  const scenario = parseScenario(value.scenario);
  if (!scenario) {
    return { ok: false, error: "The bundle’s scenario is missing or invalid." };
  }
  const result = parseRunResult(value.result);
  if (!result) {
    return {
      ok: false,
      error: "The bundle’s simulation result is missing or invalid.",
    };
  }
  let scorecard: Scorecard | undefined;
  if (value.scorecard !== undefined) {
    const parsed = parseScorecard(JSON.stringify(value.scorecard));
    if (!parsed) {
      return { ok: false, error: "The bundle’s scorecard is invalid." };
    }
    scorecard = parsed;
  }
  return {
    ok: true,
    bundle: buildRunBundle(design, scenario, result, scorecard),
  };
}

/** Triggers a browser download of the bundle as <slug>.breakpoint.json. */
export function exportRunBundleFile(bundle: RunBundle): void {
  const slug =
    bundle.design.name
      .toLowerCase()
      .replace(/[^a-z0-9]+/g, "-")
      .replace(/^-+|-+$/g, "") || "run";
  const blob = new Blob([JSON.stringify(bundle, null, 2)], {
    type: "application/json",
  });
  const url = URL.createObjectURL(blob);
  const anchor = document.createElement("a");
  anchor.href = url;
  anchor.download = `${slug}.breakpoint.json`;
  anchor.click();
  URL.revokeObjectURL(url);
}

/**
 * Guard for RunResult: strict on the design snapshot (an unknown node kind would
 * crash the replay canvas — reuses isValidGraph), forgiving on frames — they pass
 * through verbatim so an imported run replays byte-identically to the original.
 */
function parseRunResult(value: unknown): RunResult | null {
  if (!isRecord(value)) return null;
  const designSnapshot = value.designSnapshot;
  const frames = value.frames;
  const verdict = value.verdict;
  if (!isValidGraph(designSnapshot)) return null;
  if (!Array.isArray(frames)) return null;
  if (!isValidVerdict(verdict)) return null;
  return {
    scenarioId: typeof value.scenarioId === "string" ? value.scenarioId : "",
    designSnapshot,
    frames: frames as RunResult["frames"],
    verdict,
  };
}

function isValidVerdict(value: unknown): value is Verdict {
  if (!isRecord(value)) return false;
  return (
    typeof value.passed === "boolean" &&
    Array.isArray(value.failures) &&
    Array.isArray(value.advisories)
  );
}
```

    loadResult: (result, scenario) => {
      disposeWorker();
      const nodeOrder = result.designSnapshot.nodes.map((n) => n.id);
      let aggregates = emptyAggregates();
      let log: SimLogEntry[] = [];
      for (const frame of result.frames) {
        aggregates = foldAggregates(aggregates, frame, nodeOrder);
        log = appendLog(log, frame);
      }
      set({
        ...IDLE,
        status: "done",
        frames: result.frames,
        latestFrame:
          result.frames.length > 0
            ? result.frames[result.frames.length - 1]
            : null,
        aggregates,
        log,
        result,
        replayIndex:
          result.frames.length > 0 ? result.frames.length - 1 : null,
        runGraph: result.designSnapshot,
        runScenario: scenario,
      });
    },

### 4. Create `src/components/review/ImportDropzone.tsx`

New `"use client"` component. Full file:

```tsx
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import { Upload } from "lucide-react";
import { parseRunBundle, saveDesign } from "@/persistence/local";
import { saveScorecard } from "@/persistence/scorecard";
import { useDesignStore } from "@/stores/design-store";
import { useScorecardStore } from "@/stores/scorecard-store";
import { useSimStore } from "@/stores/sim-store";

export function ImportDropzone() {
  const router = useRouter();
  const [error, setError] = useState<string | null>(null);
  const [dragging, setDragging] = useState(false);

  const ingest = async (file: File | undefined) => {
    if (!file) return;
    let text: string;
    try {
      text = await file.text();
    } catch {
      setError("Could not read that file.");
      return;
    }
    const parsed = parseRunBundle(text);
    if (!parsed.ok) {
      setError(parsed.error);
      return;
    }
    setError(null);
    const { bundle } = parsed;
    // Persist so a later reload rehydrates; hydrate the stores now so the review
    // renders immediately; navigate so the URL-keyed pieces (Scorecard id, links)
    // point at the imported design.
    saveDesign(bundle.design);
    if (bundle.scorecard) saveScorecard(bundle.design.id, bundle.scorecard);
    useSimStore.getState().loadResult(bundle.result, bundle.scenario);
    useDesignStore.getState().attachDesign(bundle.design.id);
    useScorecardStore.getState().attach(bundle.design.id);
    router.push(`/review/${bundle.design.id}`);
  };

  return (
    <div className="w-full max-w-md">
      <label
        onDragOver={(e) => {
          e.preventDefault();
          setDragging(true);
        }}
        onDragLeave={() => setDragging(false)}
        onDrop={(e) => {
          e.preventDefault();
          setDragging(false);
          void ingest(e.dataTransfer.files[0]);
        }}
        className={`flex cursor-pointer flex-col items-center gap-2 rounded-xl border border-dashed px-6 py-10 text-center transition-colors ${
          dragging
            ? "border-sky-500 bg-sky-500/10"
            : "border-neutral-700 bg-neutral-900/60 hover:border-neutral-500"
        }`}
      >
        <Upload className="h-6 w-6 text-neutral-400" />
        <span className="text-sm font-medium text-neutral-200">
          Drop a run bundle here, or click to choose
        </span>
        <span className="text-xs text-neutral-500">
          A <code>.breakpoint.json</code> file exported from an interview
        </span>
        <input
          type="file"
          accept=".json,application/json"
          className="hidden"
          onChange={(e) => {
            const file = e.target.files?.[0];
            e.target.value = ""; // allow re-picking the same file
            void ingest(file);
          }}
        />
      </label>
      {error && (
        <p className="mt-3 rounded-lg border border-red-500/40 bg-red-500/10 px-3 py-2 text-xs text-red-300">
          {error}
        </p>
      )}
    </div>
  );
}
```

All `setState` calls are inside event handlers (not effects), so `react-hooks/set-state-in-effect` does not apply.

function fixtureScenario(): Scenario {
  return {
    id: "s1",

    description: "fixture",
    durationSec: 10,
    baseRps: 100,
    readRatio: 0.5,

function fixtureResult(): RunResult {
  return {
    scenarioId: "s1",
    designSnapshot: fixtureGraph(),
    frames: [
      { t: 0, perNode: {}, perEdge: {}, p95Ms: 10, errorRate: 0, servedRps: 100, events: [] },
      { t: 0.1, perNode: {}, perEdge: {}, p95Ms: 12, errorRate: 0, servedRps: 100, events: ["tick"] },

describe("parseRunBundle", () => {
  it("round-trips a bundle → identical replay frames", () => {
    const bundle = buildRunBundle(
      buildDesignRecord("d1", "My design", fixtureGraph()),
      fixtureScenario(),
      fixtureResult(),
      emptyScorecard(),

      // frames survive verbatim → replaying the import is identical to the export

      buildDesignRecord("d1", "My design", fixtureGraph()),
      fixtureScenario(),
      fixtureResult(),

      buildDesignRecord("d1", "My design", fixtureGraph()),
      fixtureScenario(),
      fixtureResult(),

    if (!badScenario.ok) expect(badScenario.error).toMatch(/scenario/i);
