# T-12.3: Resilience visible on the canvas

## Goal

Make an edge's timeout and retries readable on the canvas without selecting it, and make a retry storm visible while it happens. The idle (unselected) edge chip gains a compact settings segment (`⏱200 ↻3`) next to the existing breaker suffix. While a frame shows the edge carrying retries, the chip adds the live amplification (`↻ 3.6× load`, amber above 1.5×). The amplification is read from `latestFrame.perEdge[id]`, so replay scrubbing updates it. The chip's content moves into a small pure helper (`edge-chip.ts`) so T-12.4 can lay it out differently on short edges without touching the text rules.

**Accept:** The idle edge chip shows the edge's settings compactly (`⏱200 ↻3`, plus the existing breaker suffix). While running, an edge with retries shows its amplification (attempts ÷ fresh calls, e.g. `↻ 3.4× load`, amber above 1.5×) from `perEdge.retryRps`/`rps`. It's readable without selecting the edge, and replay scrubbing updates it.

Calls made in this plan (the lead should review them):
1. **Amplification = `rps / (rps − retryRps)`** on the frame: attempts ÷ fresh calls, per tick. Verified on `examples/retry-storm.json` + `quick-spike-3x`, no breaker: 1.00× before 10 s, **3.63×** from 11 s to 19.9 s (so the chip reads `↻ 3.6× load`, not the 3.4× quoted in the milestone's demo text), and 2.70× after the spike. At t = 20.0 s it shows **8.90× for a single 100 ms frame**, because the retry carry from the spike lands on the post-spike fresh traffic. That is a true per-tick ratio, so I'm **not clamping it** to `retries + 1`. Live it's a one-frame flicker; while scrubbing you can land on it. With the default breaker on, the ratio climbs (2.2×, 3.4×) for two frames and then disappears while the breaker is open (rps = 0).
2. **The amplification shows only when it rounds to above 1.0×** (`Math.round(amp * 10) / 10 > 1`). Otherwise an edge with retries would show a constant `↻ 1.0× load` that tells you nothing. The colour is amber when that same rounded value is above 1.5 (so 1.5× stays neutral and 1.6× turns amber), and neutral otherwise. If fresh calls are ≈ 0 (≤ 1e-9) the segment is hidden rather than dividing by zero.
3. **Timeout format:** `⏱<ms>` below 1000 ms (`⏱200`), otherwise seconds to 0.1 (`⏱1.5s`, `⏱60s`), which keeps the chip short at the 60 s max. Retries: `↻<n>`, shown when n ≥ 1. The settings segment joins its parts with a space (`⏱200 ↻3`).
4. **Settings and breaker show only on edges where they apply** (`edgeSupportsResilience`: sync, source not a queue or stream). An async edge whose stale `retries` field the engine ignores shows nothing, the same way the breaker suffix is gated today. To avoid repeating the registry lookup in the component, `toFlow` sets this as a derived flag `supportsResilience` on `FlowEdgeData`, next to `sourceKind`. That is why `flow-adapter.ts` is in the Files list. `fromFlow` ignores the flag.
5. **Segment order and separator:** base (`×1` or `50%`), `auto`, `async`, settings, breaker, amplification, joined by ` · `. Example on the storm edge mid-spike with a breaker: `×1 · ⏱200 ↻3 · breaker · ↻ 3.6× load`. Each segment's separator takes its colour, as the breaker suffix does today. No stroke change for amplification (not asked for).

### 3. New `app/src/components/canvas/edges/edge-chip.ts`

Pure TS, no React. Exact exports:

```ts
import type { EdgeFrame } from "@/lib/core";
import { isSplitSource } from "@/lib/registry";
import type { FlowEdgeData } from "@/stores/flow-adapter";

/** Rounded amplification strictly above this turns the segment amber. */
export const AMPLIFICATION_WARN = 1.5;

export type ChipTone = "muted" | "amber" | "rose";

export type ChipSegmentKey =
  | "base"
  | "auto"
  | "async"
  | "settings"
  | "breaker"
  | "amplification";

export interface ChipSegment {
  key: ChipSegmentKey;
  text: string;
  tone: ChipTone;
}

/** "⏱"-less timeout label: 200 → "200", 1500 → "1.5s", 2000 → "2s". */
export function formatTimeout(ms: number): string {
  const r = Math.round(ms);
  return r < 1000 ? `${r}` : `${Math.round(r / 100) / 10}s`;
}

/**
 * Attempts ÷ fresh calls on this frame (T-12.3): rps / (rps − retryRps).
 * null when the edge carried no retries, or fresh calls are ≈ 0.
 */
export function retryAmplification(frame: EdgeFrame | undefined): number | null {
  const retry = frame?.retryRps ?? 0;
  if (!frame || retry <= 0) return null;
  const fresh = frame.rps - retry;
  if (fresh <= 1e-9) return null;
  return frame.rps / fresh;
}

/** The unselected edge chip, as ordered segments (render joined by " · "). */
export function edgeChipSegments(
  data: FlowEdgeData | undefined,
  frame: EdgeFrame | undefined,
): ChipSegment[] { ... }
```

`edgeChipSegments` body, in this order:
1. `const isSplit = isSplitSource(data?.sourceKind);`, `share = data?.trafficShare ?? 1`, `calls = data?.callsPerRequest ?? 1`, `kind = data?.kind ?? "sync"`, `isAuto = isSplit && data?.autoShare !== false`, `resilient = data?.supportsResilience === true`.
2. Push `{ key: "base", text: isSplit ? \`${Math.round(share * 100)}%\` : \`×${Math.round(calls * 100) / 100}\`, tone: "muted" }`. This is the current text, unchanged.
3. If `isAuto`, push `{ key: "auto", text: "auto", tone: "muted" }`.
4. If `kind === "async"`, push `{ key: "async", text: "async", tone: "muted" }`.
5. If `resilient`, build `parts: string[]`. If `typeof data.timeoutMs === "number" && Number.isFinite(data.timeoutMs) && data.timeoutMs > 0`, push `` `⏱${formatTimeout(data.timeoutMs)}` ``. Let `r = Math.round(data.retries ?? 0)`, and if `r >= 1` push `` `↻${r}` ``. If `parts.length > 0`, push `{ key: "settings", text: parts.join(" "), tone: "muted" }`.
6. If `resilient && data.breaker !== undefined`, push the breaker segment from `frame?.breaker`. `"open"` gives `{ text: "breaker open", tone: "rose" }`, `"half-open"` gives `{ text: "breaker probing", tone: "amber" }`, and anything else gives `{ text: "breaker", tone: "muted" }`. These texts are the same as today's.
7. `const amp = retryAmplification(frame)`. If `amp !== null`, let `shown = Math.round(amp * 10) / 10`. If `shown > 1`, push `{ key: "amplification", text: \`↻ ${shown.toFixed(1)}× load\`, tone: shown > AMPLIFICATION_WARN ? "amber" : "muted" }`.
8. Return the array.
