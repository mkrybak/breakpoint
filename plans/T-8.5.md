# T-8.5 — Timeouts and retries

## Goal

Sync call edges get two optional, per-edge settings: `timeoutMs` (how long the caller waits) and `retries` (extra attempts after a failure). An attempt **fails** when the target sheds it (drop) or when it is slower than the timeout. Each failed attempt that still has a retry left is **re-offered to the same target on the next tick**, on top of fresh traffic. Only an attempt with no retries left counts as a client error. That is enough to reproduce the classic metastable retry storm: a brief saturation makes ~90% of attempts fail, retries ×3 multiply the load ~3.4×, and the dependency stays overloaded long after the spike ends. Without retries it recovers within 0.3 s. Per-edge state lives in a new `simulation/edge-state.ts`, which is the seam T-8.6's circuit breaker extends. The settings are edited in a new **Edge** section of the right-hand panel.

**Accept (verbatim):** Sync edges get optional `timeoutMs` and `retries`. Requests that drop or exceed the timeout at the target count as failed, and each retry re-offers load to the target next tick. Golden test, retry storm: a dependency briefly saturates, retries ×3 amplify the load, and it stays overloaded after the trigger ends. Without retries it recovers.

**The model (calls made; all go into Decisions):**
1. **Which edges.** A *policy edge* is a `sync` edge whose source is not async-category (queue/stream consumers pull per T-8.1, so they never "call") and that has `timeoutMs > 0` or `retries ≥ 1`. The engine sanitizes the values: `retries` is rounded and clamped to 0–5, `timeoutMs` is clamped to (0, 60000], and non-finite values are treated as absent. LB split edges qualify, and a retry goes back to the same edge's backend. Every other edge takes no new code path, so graphs without policy edges produce byte-identical frames.
2. **"Exceeds the timeout" is a fraction, not a cliff.** `timeoutFraction = exp(−timeoutMs / pathMs(target))`, where `pathMs(target)` is the target's mean client-path latency (its own latency plus its downstream calls, i.e. everything the caller waits for). Justification: every node's latency is M/M/1, and M/M/1 time-in-system is exponential, so `P(T > t) = e^(−t/mean)` (the same fact T-8.7 builds on). An all-or-nothing rule (`pathMs > timeoutMs ⇒ 100% fail`) would flip from 0% to 100% on a 1 ms config change, and would hide the realistic trickle of timeouts a tight timeout causes on a healthy service (200 ms against a 32 ms mean gives 0.19%), which is exactly what retries are for. Timed-out attempts **still load the target**: it served or queued them, and only the caller stopped waiting. That wasted work is the storm's fuel.
3. **Drops are tail-drop.** A full bounded queue rejects new arrivals first, so a tick's drops come from that tick's arrivals: `rejectFraction = min(1, dropped / arrivals)` (new `NodeModelOutput` field). Each inbound attempt is rejected at that rate. If drops exceed arrivals (capacity collapsing under a backlog, e.g. a kill), the excess is backlog lost and is counted as plain errors, not retried.
4. **Attempt levels.** `EdgeState.retryCarry[k]` is the flow that failed attempt k+1 and is re-offered next tick as attempt k+2. `fail = reject + (1 − reject) × timeoutFraction` applies to every level this tick. Retries ride on the edge directly, not through the source's capacity (the caller's client library resends). There is no backoff or jitter: the retry is next tick (100 ms).
5. **Errors.** A failed attempt that will be retried is not an error yet. Only exhausted attempts (failures on the last level) are client-visible. Bookkeeping: the target's drops are already counted by T-8.2's per-node split, so each policy edge adds `adjust = exhaustedRps − rejectedRps` (timeouts that gave up, minus the drops that will be retried). This goes into `clientDropped` × `clientShare(source)` and into `asyncDropped` × the rest (the edge carries its source's client share, so this matches T-8.2's attribution exactly). With `retries = 0` and no timeout, `adjust = 0` (today's numbers). Both tallies are floored at 0.
6. **Partition.** On a dead edge, propagation books fresh + retry flow as `unroutable` at the source (errors, as today), and the edge's carry resets.
7. **Latency.** The caller sees at most the timeout per attempt: `E[min(T, t)] = m(1 − e^(−t/m))`, which is `callLatencyMs`. Expected attempts per call = `attempts / fresh` on this edge this tick. A term's latency is `attempts × callLatencyMs(pathMs(target), timeoutMs)`, folded with T-8.4's weights, which are now computed from **fresh** flows so T-8.4's meaning (calls per request, LB shares) is unchanged by retries. `termMs(term, m)` is the single transform. T-8.7 applies it as a scale/cap (`v' = v·(m'/m)²`, as its plan already says).
8. **Frames.** `perEdge[id]` gains `retryRps` (retries re-offered this tick, included in `rps`) and `failRate` (share of this tick's attempts that failed), **only** on policy edges.

4. **`app/src/lib/simulation/edge-state.ts`** (new). Start with a header comment: "Per-edge resilience state carried tick-to-tick (T-8.5 timeouts/retries; T-8.6 adds the circuit breaker here). Imports ./engine for Flow helpers; the cycle is init-safe like node-models'." Then:
   ```ts
   import type { ComponentKind, DesignEdge, DesignGraph } from "@/lib/core";
   import { getComponentDef } from "@/lib/registry";
   import { addFlow, flowRps, scaleFlow, zeroFlow, type Flow } from "./engine";
   import { timeoutFraction } from "./node-models";

   export const MAX_RETRIES = 5;
   export const MAX_TIMEOUT_MS = 60000;

   /** Sanitized per-edge settings. T-8.6 adds `breaker?`. */
   export interface EdgePolicy { timeoutMs?: number; retries: number }

   /** Carried tick-to-tick. retryCarry[k] = flow that failed attempt k+1, re-offered next tick as attempt k+2 (length = retries). T-8.6 adds `breaker`. */
   export interface EdgeState { retryCarry: Flow[] }

   /** Can this edge carry timeouts/retries? Sync, and its source isn't a queue/stream (consumers pull, T-8.1). Shared with the edge inspector. */
   export function edgeSupportsResilience(edge: DesignEdge, sourceKind: ComponentKind | undefined): boolean {
     return edge.kind === "sync" && sourceKind !== undefined && getComponentDef(sourceKind).category !== "async";
   }

   /** Sanitize an edge's fields; null = no policy (the edge behaves exactly as before T-8.5). */
   export function edgePolicy(edge: DesignEdge): EdgePolicy | null {
     const t = edge.timeoutMs;
     const timeoutMs = typeof t === "number" && Number.isFinite(t) && t > 0 ? Math.min(t, MAX_TIMEOUT_MS) : undefined;
     const r = edge.retries;
     const retries = typeof r === "number" && Number.isFinite(r) ? Math.min(MAX_RETRIES, Math.max(0, Math.round(r))) : 0;
     if (timeoutMs === undefined && retries === 0) return null;
     return timeoutMs === undefined ? { retries } : { timeoutMs, retries };
   }

   /** Policy per edge id, in graph.edges order, for edges that support one. Fixed per run. */
   export function buildEdgePolicies(graph: DesignGraph): Map<string, EdgePolicy> {
     const kindById = new Map(graph.nodes.map((n) => [n.id, n.kind]));
     const policies = new Map<string, EdgePolicy>();
     for (const edge of graph.edges) {
       if (!edgeSupportsResilience(edge, kindById.get(edge.source))) continue;
       const policy = edgePolicy(edge);
       if (policy) policies.set(edge.id, policy);
     }
     return policies;
   }

   export function initialEdgeState(policy: EdgePolicy): EdgeState {
     return { retryCarry: Array.from({ length: policy.retries }, zeroFlow) };
   }

   /** Retries to re-offer this tick: Σ retryCarry. */
   export function pendingRetries(state: EdgeState): Flow {
     return state.retryCarry.reduce(addFlow, zeroFlow());
   }

   export interface EdgeTickInput {
     /** first attempts the source sent this tick (PropagationResult.freshPerEdge) */
     fresh: Flow;
     /** partitioned this tick: propagation booked everything unroutable at the source */
     dead: boolean;
     /** the target's rejectFraction this tick */
     rejectFraction: number;
     /** the target's mean client-path latency this tick (uncapped) */
     targetPathMs: number;
   }

   export interface EdgeTick {
     next: EdgeState;
     /** retries offered this tick */
     retryRps: number;
     /** share of this tick's attempts that failed; 0 with no attempts, 1 on a dead edge */
     failRate: number;
     /** attempts the target shed (already inside its `dropped`) */
     rejectedRps: number;
     /** failed attempts with no retry left: the caller gives up */
     exhaustedRps: number;
   }

   /**
    * One tick of an edge's retry bookkeeping. fail = reject + (1 − reject) × timeoutFraction
    * hits every attempt level alike; level k's failures carry to level k+1; the last
    * level's failures are exhausted.
    */
   export function stepEdge(policy: EdgePolicy, state: EdgeState, input: EdgeTickInput): EdgeTick {
     const retry = pendingRetries(state);
     const retryRps = flowRps(retry);
     const attemptsRps = flowRps(input.fresh) + retryRps;
     if (input.dead) {
       return { next: initialEdgeState(policy), retryRps, failRate: attemptsRps > 0 ? 1 : 0, rejectedRps: 0, exhaustedRps: 0 };
     }
     const reject = Math.min(1, Math.max(0, input.rejectFraction));
     const timedOut = policy.timeoutMs === undefined ? 0 : timeoutFraction(input.targetPathMs, policy.timeoutMs);
     const fail = reject + (1 - reject) * timedOut;
     const levels = [input.fresh, ...state.retryCarry];
     return {
       next: { retryCarry: levels.slice(0, policy.retries).map((level) => scaleFlow(level, fail)) },
       retryRps,
       failRate: attemptsRps > 0 ? fail : 0,
       rejectedRps: attemptsRps * reject,
       exhaustedRps: flowRps(levels[policy.retries]) * fail,
     };
   }
   ```
   Format with prettier (`npm run format` or the editor). The one-liners above are for brevity.
