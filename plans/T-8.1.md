# T-8.1 — Queues actually buffer

## Goal

Today every node, queues included, holds at most 0.5 s of capacity (`maxQueue`, `node-models.ts:181`). A queue in front of slow workers therefore forwards the whole burst, and the workers overflow and drop. That reads as client errors, so the sim punishes the textbook "put a queue in front of it" answer. After this task, async-category nodes (`queue`, `stream`) get their own node model. It holds a large backlog, capped by a configurable `retentionMsgs` instead of the 0.5 s rule. It forwards downstream only what its consumers can pull this tick (pull semantics). Each frame now reports per-async-node `queueDepth` (messages) and `lagSec` (consumer lag in seconds). Non-async nodes keep their exact current math and frame shape.

**Accept (verbatim):** Async-category nodes (queue, stream) hold a large backlog: a configurable retention (instead of the 0.5s-of-capacity cap every node gets today, `node-models.ts:181`). Consumers drain it at their own capacity (pull semantics). `SimFrame` carries queue depth and consumer lag (seconds) per async node. Golden test, the review's repro: client → app (5) → queue → workers (2), 1500 RPS, spike ×3 for 3s ⇒ **0% client errors**, backlog grows then drains, lag returns to 0.

**Model (verified by prototype; the full test suite, lint and depcruise all pass with it):**
- **Units.** The engine carries backlog in RPS units: a carried `Q` re-enters next tick's demand as `Q` RPS for 0.1 s, i.e. `Q / 10` messages. So `queueDepth = flowRps(queued) / TICKS_PER_SEC` (messages), and the retention cap in carry units is `retentionMsgs × TICKS_PER_SEC`. `perNode.queued` keeps its current meaning (RPS units) for every node.
- **Pull.** An async node serves `min(demand, ownCap, drainRps)`. `drainRps` = min over its forward outbound edges `e` (same forward rule as propagation) of `headroom(target) / e.trafficShare`. Headroom = the target's effective capacity this tick (its kind's `CapacityFn` with its `aliveFraction`) minus the target's own carried backlog, floored at 0. An async target counts zero backlog, since it buffers on its own. A dead (partitioned) consumer edge makes `drainRps = 0`: the backlog holds instead of dropping. An async node with no forward consumer edges has `drainRps = Infinity` (a sink queue serves everything, same as today). Edges with `trafficShare <= 0` are skipped. T-8.3 renames the share to `callsPerRequest` and must update this divisor.
- **Retention.** A new registry config field `retentionMsgs` on `queue` and `stream`, default 1,000,000 messages. Backlog beyond it drops (booked as `dropped`, and so still counted into `errorRate`; T-8.2 separates async drops). A down async node (`ownCap === 0`) retains nothing and drops everything, the same as every other down node (T-2.3 decision).
- **Util/state.** `util = max(ingestUtil, overflow / retentionCap)`, where `ingestUtil = inflowTotal / ownCap`. A filling buffer goes hot at 70 % and saturated at 90 %, and goes overloaded exactly when it sheds. With no backlog, util equals today's value.
- **Latency.** `latencyMs = baseMs / (1 − min(ingestUtil, 0.95))`. It is the enqueue cost only, with no queue-wait term: backlog wait is consumer lag, not producer latency.
- **Lag.** `lagSec = depth / drainedRps` while consumers drain (`drainedRps = flowRps(served)`). With depth 0, lag is 0. With depth > 0 and nothing drained, the backlog ages: `prevLag + 1/TICKS_PER_SEC`. This is a "time to catch up at the current rate" estimate, which equals oldest-message age at the peak of a burst.
- **Golden numbers** (hand-checked, then confirmed by the prototype): the spike runs over ticks 50–79 at 4500 RPS against a 2000 RPS drain, so +250 msgs/tick. Peak depth is 7500 msgs at tick 79, and lag 7500 / 2000 = 3.75 s. Afterwards it drains at −50 msgs/tick and hits 0 at tick 229. Workers are saturated (util exactly 1, never over) on ticks 50–229. On current `main` the same run fails with 33.3 % errors.

**errorRate split:** not needed. With buffering nothing drops anywhere on the repro, so `Σdropped / offered` is already 0. T-8.2 owns the split.

Calls made (lead, review):

     ```ts
       return ({ node, def, inflow, queuedPrev, aliveFraction, drainRps = Infinity }) => {
         const cap = capacity(node, def, aliveFraction);
         const ownCap = cap.split ? cap.readRps + cap.writeRps : cap.readRps;
         const demand = addFlow(inflow, queuedPrev);
         const demandTotal = flowRps(demand);
         const servedTotal = Math.min(demandTotal, ownCap, Math.max(0, drainRps));
         const served = splitByFlow(demand, demandTotal, servedTotal);
         const overflow: Flow = {
           read: demand.read - served.read,
           write: demand.write - served.write,
         };
         const overflowTotal = flowRps(overflow);
         const retention =
           ownCap > 0
             ? configNumber(node, def, "retentionMsgs", DEFAULT_RETENTION_MSGS) * TICKS_PER_SEC
             : 0;
         const queuedTotal = Math.min(overflowTotal, retention);
         const ingestUtil = ratio(flowRps(inflow), ownCap);
         const util = Math.max(ingestUtil, ratio(overflowTotal, retention));
         return {
           served,
           queued: splitByFlow(overflow, overflowTotal, queuedTotal),
           dropped: overflowTotal - queuedTotal,
           util,
           latencyMs: def.latency.baseMs / (1 - Math.min(ingestUtil, MAX_MM1_UTIL)),
           state: nodeState(util, ownCap),
         };
       };
     ```

   - Two pure helpers (exported, doc-commented):
     ```ts
     /** Max total RPS of `mix`-shaped flow a consumer takes this tick on top of its own backlog. Infinity when unlimited. */
     export function consumerHeadroomRps(cap: EffectiveCapacity, backlog: Flow, mix: Flow): number {
       if (!cap.split) return Math.max(0, cap.readRps - flowRps(backlog));
       const read = Math.max(0, cap.readRps - backlog.read);
       const write = Math.max(0, cap.writeRps - backlog.write);
       const total = flowRps(mix);
       if (total === 0) return read + write;
       const byRead = mix.read > 0 ? read / (mix.read / total) : Infinity;
       const byWrite = mix.write > 0 ? write / (mix.write / total) : Infinity;
       return Math.min(byRead, byWrite);
     }

     /** Consumer lag: depth ÷ drain rate; an undrained backlog ages one tick. */
     export function consumerLagSec(depthMsgs: number, drainedRps: number, prevLagSec: number): number {
       if (depthMsgs === 0) return 0;
       if (drainedRps > 0) return depthMsgs / drainedRps;
       return prevLagSec + 1 / TICKS_PER_SEC;
     }
     ```

     ```ts
     /** pull semantics: what an async node's consumers can take this tick */
     const pullRps = (id: string, mix: Flow): number => {
       let limit = Infinity;
       for (const e of consumers.get(id) ?? []) {
         if (e.trafficShare <= 0) continue;
     ```
